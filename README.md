# Image2Graph

이미지에서 데이터까지, 차트를 더 빠르게 만들어보세요.

## 🚀 주요 기능

- **이미지 업로드**: 스크린샷/사진을 드래그 앤 드롭하면 분석을 시작합니다
- **AI 변환**: 데이터 테이블과 Vega-Lite 스펙을 자동 생성합니다
- **간편 편집/내보내기**: 색상/레이블을 수정하고 JSON/CSV로 저장하세요

## 🛠️ 기술 스택

### Frontend
- React 18
- TypeScript
- Vite
- Vega-Lite
- Zustand

### Backend
- Node.js
- Express
- Google Gemini API

## 📦 설치 및 실행

### 백엔드 서버
```bash
cd server
npm install
npm run dev
```

### 프론트엔드
```bash
cd web
npm install
npm run dev
```

## 🔧 환경 설정

1. `server` 폴더에 `.env` 파일 생성:
```
GOOGLE_API_KEY=your_google_api_key_here
MODEL_ID=gemini-1.5-pro
```

2. Google AI Studio에서 API 키 발급:
   - https://aistudio.google.com/ 접속
   - "Get API key" 클릭하여 새 API 키 생성

## 🌐 접속 주소

- **프론트엔드**: http://localhost:5173
- **백엔드 API**: http://localhost:4000

## 📝 사용법

1. 이미지를 업로드하거나 템플릿을 선택하세요
2. AI가 자동으로 차트를 생성합니다
3. 색상, 레이블 등을 편집하세요
4. JSON 또는 CSV로 내보내세요
